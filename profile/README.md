A HYZIS é uma empresa brasileira de engenharia de software. Construímos em Go, sobre o [Arandu](https://github.com/arandu-io), e publicamos aqui os módulos que as nossas aplicações usam. Cada módulo cuida de uma responsabilidade, e o tenant de cada leitura e escrita vem do `security.Grant` da aplicação.

### Módulos

**Plataforma e SaaS multi-tenant**

| Módulo | Para que serve |
| --- | --- |
| [arandu-permission](https://github.com/hyz-is/arandu-permission) | Grupos e permissões; as policies em Go continuam sendo a autoridade |
| [arandu-wallet](https://github.com/hyz-is/arandu-wallet) | Carteiras, ledger e transferências em int64, com idempotência |
| [arandu-activitylog](https://github.com/hyz-is/arandu-activitylog) | Log de atividade por tenant: quem fez o quê, antes e depois |
| [arandu-impersonate](https://github.com/hyz-is/arandu-impersonate) | Agir como um usuário a partir do admin, com tudo registrado |
| [arandu-tags](https://github.com/hyz-is/arandu-tags) | Taxonomias e tags de domínio por tenant |
| [arandu-markdown](https://github.com/hyz-is/arandu-markdown) | Markdown com HTML sanitizado, sumário e tempo de leitura |
| [arandu-swagger](https://github.com/hyz-is/arandu-swagger) | OpenAPI 3.1 gerado das rotas reais, com Swagger UI |
| [arandu-webhook](https://github.com/hyz-is/arandu-webhook) | Webhooks assinados de saída e verificados de entrada |
| [arandu-affiliate](https://github.com/hyz-is/arandu-affiliate) | Programa de afiliados com comissões multinível |
| [arandu-br](https://github.com/hyz-is/arandu-br) · [arandu-viacep](https://github.com/hyz-is/arandu-viacep) | CPF, CNPJ, CEP, BRL e endereço a partir do CEP |
